# very-claude-plugins

Free, open-source plugins for Claude Code.

| Plugin | What it does |
| --- | --- |
| [nudge-me](plugins/nudge-me) | Nudges you to take breaks, go to bed, and anything else you ask for with `/nudge` or by asking Claude. |

## Install

At the prompt of a Claude Code session:

```
/plugin install nudge-me --marketplace austincparker/very-claude-plugins
```

Answer `y` to add the marketplace, then pick a scope. From a shell:

```
claude plugin install nudge-me --marketplace austincparker/very-claude-plugins
```
